# Avatares y movimiento de la interfaz

Comprobaciones con datos ficticios y nombres largos, con fotografías e iniciales, en ambos temas y en anchos de 390, 1024 y 1440 píxeles.

- Avatares circulares, incluso bajo presión de un contenedor flex.
- Tarjetas con geometría estable durante hover.
- Panel lateral, barra superior y contenido sincronizados durante la animación.
- Iconos sin recortar y sin saltos verticales.
- Transiciones desactivadas cuando se solicita movimiento reducido.
