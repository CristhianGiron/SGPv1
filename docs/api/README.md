# API y Postman

La [guía Postman](guia-postman.md) mantiene el punto de entrada original e incluye las variables de entorno. Los ejemplos están en `postman/`, separados por dominio.

- [Autenticación](postman/autenticacion.md) y [cuentas](postman/cuentas.md).
- [Catálogos](postman/catalogos.md) y [paralelos e inscripciones](postman/practicas.md).
- [Entrevistas y fichas](postman/formularios.md), [planificaciones didácticas](postman/planificaciones.md) y [notificaciones](postman/notificaciones.md).
- [Documentos L.1–L.6](postman/documentos/README.md).
- [Autoguardado, vista previa de PDF y expediente ZIP](borradores-vista-previa-expediente.md).
- [Evidencias, jornadas y asistencias](postman/evidencias-jornadas.md).
- [Alcance institucional y portadas](postman/alcance-institucion.md).
- [Recorrido de prueba y scripts de Postman](postman/pruebas-flujo.md).

Los identificadores de los cuerpos JSON son ejemplos y deben reemplazarse por registros accesibles a la cuenta autenticada. Una ruta existente no garantiza que cualquier rol pueda ejecutarla: consulte las condiciones del módulo y la [matriz de permisos](../producto/permisos-practicas.md).
