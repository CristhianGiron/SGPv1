# Exportaciones históricas de requisitos

Los archivos de esta carpeta son fuentes de trabajo o exportaciones de un
levantamiento anterior. Pueden contener perfiles o capacidades que no existen
en la implementación actual y no deben utilizarse como catálogo vigente.

La única referencia actual de requisitos, actores y casos de uso es
[especificacion.md](../../especificacion.md). La fuente original del proceso
ABP se conserva en el directorio superior como material de referencia, no como
descripción automática del alcance implementado.
