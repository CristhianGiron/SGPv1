# Producto y flujos de trabajo

Estas guías describen el uso del sistema y las decisiones de interfaz. No sustituyen los requisitos ni conceden permisos adicionales.

## Flujos y alcance

1. [Configuración institucional](configuracion-institucional.md): valores predeterminados UNL y ampliación a otras instituciones, facultades y carreras.
2. [Permisos de prácticas](permisos-practicas.md): capacidades por rol y restricciones de acceso.
3. [Navegación por práctica](flujo-por-practica.md): selección de práctica y trabajo dentro de su contexto.
4. [Administración y personal](flujos-administracion-personal.md): recorridos por entidades y asignaciones.
5. [Experiencia de trabajo](experiencia-de-trabajo.md): resumen, documentos guiados, borradores, agenda y notificaciones.
