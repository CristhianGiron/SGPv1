# Imágenes de acceso UNL

Archivos proporcionados por el usuario el 1 de noviembre de 2026 para el acceso del SGP:

- `unl-campus.jpg`: copia de `c.jpg`, fotografía panorámica del campus.
- `unl-logo.png`: copia de `unl_0_2.png`, logo con fondo transparente.

Se conservan los archivos originales sin modificación de píxeles. El recorte del espacio transparente y el contraste de las letras del logo sobre la cabecera azul se realizan mediante CSS; el escudo conserva su color. Ambos recursos se empaquetan con React y se utilizan cuando la institución configurada tiene código `UNL`.
